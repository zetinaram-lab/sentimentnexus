## 🎯 Project Vision

**SentimentNexus** is an open-source, real-time gold trading dashboard built as a **full-stack development learning project** with AI assistance.

The goal was to explore modern web technologies, API integration, and serverless architecture while building something useful for the trading community.

## 💬 Frequently Asked Questions

### **Q: Is it okay to use AI for coding?**
**A:** Absolutely! AI is a tool, like Stack Overflow or documentation. What matters is:
- Understanding what the code does
- Being able to maintain and debug it
- Using it to learn, not to cheat
- Being transparent about it

### **Q: Does AI-assisted mean you didn't code it?**
**A:** No. AI assistance is like pair programming - I drove all decisions, requirements, and architecture. The AI helped with implementation, debugging, and best practices. Every line of code was reviewed and understood.

### **Q: Why be transparent about AI use?**
**A:** Because honesty builds trust. In professional settings, using AI tools effectively is a valuable skill. Hiding it would be dishonest and miss the opportunity to showcase modern workflow competency.

### **Q: What did you learn from this project?**
**A:** Everything listed in the "Learning Outcomes" section above. More importantly, I learned how to:
- Define and scope a project
- Build something from scratch to production
- Handle real-world challenges (APIs, security, performance)
- Engage with a community
- Use AI as a learning accelerator
