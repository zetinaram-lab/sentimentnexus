```
🚀 Just launched SentimentNexus - A free, open-source gold trading dashboard!

Built as a learning project to explore real-time data streaming and Telegram bot APIs.

✨ What it does:
• Tracks XAU/USD (gold) prices in real-time (2-second updates)
• Technical analysis: RSI, MACD, Bollinger Bands, SMAs
• Free Telegram bot with automated price alerts
• No signup, no ads, completely free

🛠️ Tech Stack:
React 18, TypeScript, Vite, shadcn/ui, Tailwind CSS, Vercel Functions, Chart.js

📊 Features:
• Multi-source API with automatic fallback (Binance, CoinGecko, CoinCap)
• Real-time technical indicators
• Automated trading signals
• Export data to CSV

🌐 Try it live: https://sentimentnexus.vercel.app
💻 Open source: https://github.com/zetinaram-lab/sentimentnexus
🤖 Telegram: @SentimentNexusBot

This was built with AI assistance (Claude Sonnet) as a full-stack development learning project. The goal was to understand API integration, real-time data handling, and serverless architecture.

💡 Looking for feedback from the community! What features would you add?

#WebDevelopment #React #TypeScript #OpenSource #Trading #Gold #Fintech #AI #FullStack #LearningInPublic #BuildInPublic #SideProject #TradingTools
```
